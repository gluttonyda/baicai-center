## 不进入公开仓库的内容

以下内容属于运行数据或敏感数据，不应提交：

- `.env`
- `baicai-work/.env`
- `rclone.conf`
- 数据库备份
- 运行日志
- Worker runtime 缓存
- duplicate/dedupe 分析结果
- 真实媒体路径清单

对应规则已写入：

- `.gitignore`
- `.dockerignore`
- `baicai-work/.dockerignore`

## 公开前检查

推荐执行：

```bash
git status --short --ignored
git add --dry-run .
git ls-files -z | xargs -0 grep -n -I -E "API_TOKEN=|DB_PASSWORD=|BEGIN .*PRIVATE|ghp_|github_pat_"
```

正常情况下，真实 `.env`、备份、日志、缓存文件应显示为 ignored，不应出现在 `git add --dry-run` 输出中。
