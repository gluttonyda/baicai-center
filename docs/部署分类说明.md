# 部署分类说明

当前仓库已整理为生产运行目录：根目录保留 `Center` 相关代码，`Worker` 节点运行包统一放在 `baicai-work/`。

## 目录划分

### 根目录

放置只需要部署在 `Center` 节点上的代码和运维脚本：

- `main.py`
- `init_sync.py`
- `Dockerfile`
- `docker-compose.yml`
- `requirements.txt`
- `IMPORT_DRIVE_ACCOUNTS.sql`
- `SCHEMA_MINIMAL.sql`
- `scripts/`
- `docs/`

### `baicai-work/`

放置只需要部署在 `Worker` 节点上的代码：

- `worker.py`
- `scanner.py`
- `requirements.txt`
- `sanitize.sh`
- `Dockerfile`
- `docker-compose.yml`
- `.env.example`

## 使用建议

- `Center` 节点直接使用根目录启动。
- `Worker` 节点只导出 `baicai-work/` 目录即可。
- 当前仓库不再保留历史测试副本；若要做大改，先在独立测试目录完成验证后再回灌生产。
